# 云南大学 · 历史人物 3D 游学

3D 版的云南大学东陆校区（艺术化重构），可以走进至公堂参观。

参考 [ruanyf/luxun-native-place](https://github.com/ruanyf/luxun-native-place) 的形式，全部几何与贴图由代码程序化生成（Three.js），无需加载任何外部模型与图片资源。

**在线访问**：<https://liudonghua123.github.io/ynu-heritage-3d/>

## 五处地标 · 五组人物

| 地标 | 人物 |
| --- | --- |
| 会泽院 | 唐继尧（倡办东陆大学）、董泽（首任校长，1923） |
| 云大校门 | 银杏道 · 九十五级龙门道 |
| 至公堂（可入内） | 熊庆来（1937–1949 长校）、闻一多（《最后一次讲演》，1946）、李广田（1952–1968 校长） |
| 映秋院 | 李广田 |
| 翠湖之畔 | 袁嘉谷（经济特科第一） |

至公堂室内设有讲演台、匾额、滇池山水画与先贤画像墙，可点击走近细看。

## 功能

- 全景环视（拖拽旋转、滚轮缩放）与步行漫游（WASD / 方向键，Esc 退出）
- 自动游学路线（约 1 分钟 · 5 处地标）
- 日景 / 暮景切换
- 点击场景标记飞行运镜
- 人物档案对话框
- 小地图与罗盘
- 移动端触控支持

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

依赖：Node 20+，Three.js 0.180，Vite 7。
